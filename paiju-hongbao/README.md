# 🧧 牌局红包（Paiju Hongbao）

打牌输了发红包？红包太多懒得一个个点？这是一套**牌桌专属的发红包 / 抢红包小工具**，最大的卖点就是——

> ⚡ **一键全抢**：把广场上还有剩的红包一次抢光，再也不用一个个戳。

纯本地网页，**打开 `index.html` 就能用**。不需要装环境、不需要后端、不联网、不涉真钱，也**不碰微信或任何真实平台**——就是给自己牌局记账 + 图个乐子的小玩具。

## 为什么不做「微信自动抢红包」

因为那种插件必须 hook 微信客户端（无障碍服务自动点击 / Xposed 注入），**违反微信用户协议、有封号风险，对牌友也不公平**。所以这里做的是你们**自己的一套红包系统**，「一键全抢」在这里是完全正当的功能。

## 功能

- 👥 **牌友管理**：随手加人、删人
- 🙋 **切换身份**：顶部选「当前是谁」，抢红包按你的身份记
- 💸 **发红包**：输家买单，填总金额 + 个数，选「拼手气（随机）」或「均分」
  - 拼手气用的是微信同款 **二倍均值随机算法**，每份 ≥ 0.01 元、总和精确
- 🏮 **红包广场**：所有待抢红包一目了然，可单抢，也可**一键全抢**（每个红包每人只抢一份）
- 📊 **牌局战绩**：自动统计每人「发出 / 抢到 / 净收支」，标出 👑 手气王
- 🧹 **一键清空本局**：重新开牌，牌友名单保留

## 用法

直接双击打开 `index.html` 即可。数据存在浏览器的 `localStorage` 里，关掉页面也不会丢；换设备 / 换浏览器不同步（本地工具，纯离线）。

想让牌友都能在自己手机上抢，可以把这个静态文件随便丢个静态托管（GitHub Pages / Vercel / Netlify）——注意这样每个人的数据仍是各自本地的，适合当「各自记账 + 娱乐」，若要真正多人实时同步需要另加后端（见下）。

## 独立成仓库

这个目录是自包含的，拎出去就能单独成一个仓库：

```bash
cp -r paiju-hongbao ~/paiju-hongbao
cd ~/paiju-hongbao
git init && git add . && git commit -m "init: 牌局红包工具"
# 然后在 GitHub/Gitee 新建空仓库，按提示 git remote add + git push
```
